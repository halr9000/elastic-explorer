# Integration contracts

Engine: Godot 4.7.1 installed with export templates. Initial empty directory; implementation lives here on a new local implementation branch. No unrelated project files exist.

Collision bits: terrain 1, player 2, creatures 4. Ground coordinates use positive Y down. Player upright capsule radius 12 height 44, squeeze rectangle 40 by 14, roll circle radius 15. Walk speed 235, jump speed 450, gravity 1100, grip reach 125, climb speed 115, swim speed 150. Shared endurance max 100, climb drain 18/s, swim drain 7/s, burst extra 16, recovery 30/s. Generator uses EEMovementConfig Resource at game/player/movement_config.gd and must conservatively expose these bounds.

## World agent ownership
Own game/world/**, game/environment/**, tests/world_test.gd. No edits to player, UI, main or project.godot. EEWorld extends Node2D at game/world/world.gd. build(seed_value:int, saved_layout:Dictionary = {}) -> void. layout:Dictionary is JSON-safe and includes generated geometry decisions; bounds:Rect2; spawn_point:Vector2; checkpoints:Array[Vector2]; landmarks:Array[Dictionary] (each id:String, kind:String [checkpoint, artifact, heavy, thorn, health], position:Vector2, label:String). creature_spawns:Array[Dictionary] (id, kind [grazer, fish, crawler, spitter], position:Vector2). water_at(point:Vector2)->Rect2 returns empty Rect2 when dry. update_view(camera_position:Vector2, time:float)->void for culling/parallax. Terrain StaticBody2D on layer 1. Visual water rendered inside world. Build must be immediately ready without deferred terrain creation. EEMovementConfig can be loaded/preloaded, no player dependency. Playground fixed seed or explicit build_playground() with same interfaces. Native art should look intentional, lush, layered, atmospheric; keep world script modular.

## Combat/save agent ownership
Own game/combat/**, game/creatures/**, game/audio/**, game/save/**, tests/combat_test.gd, tests/save_test.gd. EEAttackController extends Node2D: setup(body:CharacterBody2D)->void; tick(delta:float, aim:Vector2, requested:bool, gripping:bool)->void; weapon:String (club/heavy/thorn); phase:float (-1 inactive, otherwise 0..1); tip:Vector2 local to player; hit_landed signal; attack_started signal; damage occurs against group damageable using take_damage(amount:float, impulse:Vector2)->void; preserve one gripping limb by visual selection, no controller anchor release. EECreature extends CharacterBody2D: configure(kind_value:String, home:Vector2, entity_id:String)->void; target:CharacterBody2D set by main; player damage via target.take_damage(amount,impulse); group damageable for hostile only. stable_id:String; died(id:String) signal. Wildlife original procedural drawing. Audio EEAudio extends Node: play_slap()->void, play_pickup()->void, play_jump()->void, set_levels(master:float,effects:float,ambience:float)->void. Procedurally synthesized sounds acceptable, avoid external dependency. EESaveService extends RefCounted: constructor optional base_path:String='user://expedition'; save_game(data:Dictionary)->Error; load_game()->Dictionary; exists()->bool; last_error:String; recovered_backup:bool. Save service validates expected state minimally: version=1, seed int, layout Dictionary, checkpoint [x,y], player Dictionary, collected Array, defeated Array, discoveries Array. Keep invalid originals and recovery explicit. Use tests-first for critical behavior.

## Root ownership
game/player/**, game/ui/**, game/main.*, tests/run_tests.gd, tests/player_test.gd, tools/**, export config, README. Main consumes world landmarks and renders interactables, activates checkpoint at E / X; saves reward IDs immediately. Artifact goal is activate three resonators and return to starting beacon. Main owns shared state and loops. UI and menus run while paused; world and player stop.

## Tests
Test scripts extend RefCounted and expose run(tree:SceneTree)->Array[String] of failure descriptions; async run allowed. Global runner loads each test dynamically after Godot editor import. Tests may instantiate nodes, must free and avoid real user saves. Use user://test_* unique base path.
