# Art and audio provenance

All game visuals are original procedural geometry authored for this project. Terrain, plants, ruins, parallax scenery, creature limbs, wildlife, and artifacts are rendered by GDScript. The atmosphere shader adds subtle grain and vignette. No supplied reference image has been copied into the game.

Sound effects and ambience are synthesized locally by `game/audio/audio.gd` into PCM streams. No external audio samples, model downloads, or network services are required.

UI uses Godot's bundled font. Godot's engine license and third-party notices are available in the engine distribution and About dialog of the editor.
